## API route notes
- Route is `app/api/chat/route.ts`. Prompt is `lib/system-prompt.ts`,
  kept separate so ~20 pages of site content can grow there later.
- Model `claude-sonnet-4-5`, confirmed working through the SDK.
- `new Anthropic()` with no arguments reads `ANTHROPIC_API_KEY` from the
  environment by itself. That is why `.env.local` exists.
- GOTCHA: env vars are read ONCE when the server starts. A server that
  was started before you saved the key holds a blank key forever.
  Restart the dev server after editing `.env.local`.
- GOTCHA: dotfiles are hidden on macOS. Open with `open -e .env.local`,
  or press `Cmd`+`Shift`+`.` in Finder.
- GOTCHA: TextEdit does not write to the file until you press `Cmd`+`S`.
  Check the key landed without printing it:
  `awk -F= '/^ANTHROPIC_API_KEY=/ { v=substr($0, index($0,"=")+1); print "prefix:", substr(v,1,7); print "length:", length(v) }' .env.local`
  A good key reads `sk-ant-` and about 108 characters.
- Test from the terminal:
  `curl -sS -X POST http://localhost:3000/api/chat -H "Content-Type: application/json" -d '{"messages":[{"role":"user","content":"كم تكلفة موقع شركة؟"}]}'`
  First request is slow — Next.js compiles the route on first hit.
- The dev server start-up config is `.claude/launch.json` in the PARENT
  folder (`Desktop/Agentic`), not inside the project. It runs
  `npm run dev --prefix wael-arabic-agent`, which is verified working.
- `lsof -nP -iTCP:3000 -sTCP:LISTEN` prints nothing and exits 1 when the
  server is down. That is not an error. It can disagree with Claude's
  own server list — trust Claude's list.

## Arabic / RTL decisions
- Font is IBM Plex Sans Arabic, loaded in `layout.tsx` as
  `--font-arabic`.
- GOTCHA: setting `font-family` on `body` is NOT enough. Tailwind's
  `font-sans` class on any wrapper div overrides it. Fix was to point
  the token itself at the Arabic font in `globals.css`:
  `--font-sans: var(--font-arabic)`.
- `<html lang="ar" dir="rtl">` — `lang` is for SEO + screen readers,
  `dir` flips the whole document.
- GOTCHA: Tailwind has logical vs physical utilities. `items-start`
  flips automatically under RTL. `text-left` / `text-right` do NOT —
  they must be changed by hand.
- `page.tsx` still has English boilerplate copy and the stock Vercel
  buttons. Replace before showing anyone.
